## Descrição

O sistema demonstra herança e polimorfismo. Cachorro e Gato herdam de Animal e sobrescrevem o método emitirSom(). Uma lista de Animal armazena os dois objetos e, ao chamar o método, cada animal executa seu próprio comportamento.
